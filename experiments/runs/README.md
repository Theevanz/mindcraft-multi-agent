# runs/ — per-iteration records

One `<n>.md` per run following the template in `../PROTOCOL.md`, plus the
run's raw console as `<n>.console.log` (gitignored — large, never read raw;
score via `../tools/analyze_runs.py` and grep on anomalies only).

Numbering continues the story: the pre-lab runs are R0 (11-25 peak, L8) —
first lab run at baseline is run 1.
